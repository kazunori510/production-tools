# 現場ツール(車両予約・機材一覧)

Notionの「車両予約表」「私物機材リスト」「レンタル機材リスト」を、スマホからサッと見たり登録したりできるWebアプリです。

- 車両予約：一覧表示 + 新規登録(＋ボタン)
- 機材一覧：私物/レンタルの切り替え、検索、カテゴリ絞り込み(閲覧のみ)

---

## 0. 全体の流れ

1. Notion側で「インテグレーション」を作り、シークレットキーを発行する
2. 対象の3つのデータベースをそのインテグレーションと共有する
3. このコードをGitHubに置く
4. Vercelでデプロイし、環境変数にシークレットキーを設定する
5. 発行されたURLをスマホのホーム画面に追加する

所要時間の目安：1〜2時間(初回のみ)。以降の更新は自動で数分で反映されます。

---

## 1. Notionインテグレーションを作る

1. ブラウザで https://www.notion.so/my-integrations を開く(Notionにログインした状態で)
2. 「+ New integration」をクリック
3. 名前を入力(例：現場ツール)、関連ワークスペースを選択して「Submit」
4. 「Internal Integration Secret」と書かれた欄に `secret_...` から始まる文字列が表示されるので、コピーしておく(後で使います。他人に共有しないこと)

## 2. 3つのデータベースをインテグレーションと共有する

対象は次の3つです。

- 車両予約表
- 私物機材リスト
- レンタル機材リスト

それぞれのデータベースをNotionで開き、右上の「…」または「Connections」から、手順1で作ったインテグレーション(例：現場ツール)を追加してください。
(共有し忘れると、アプリ側で「データベースが見つかりません」というエラーになります)

---

## 3. コードをGitHubに置く

1. https://github.com にログイン(アカウントがなければ作成)
2. 右上の「+」→「New repository」で新しいリポジトリを作成(例：production-tools)。Public/Privateどちらでも構いません
3. このフォルダの中身一式を、作成したリポジトリにアップロードする
   - GitHubの画面で「uploading an existing file」からドラッグ&ドロップでアップロードできます
   - `node_modules` フォルダは含まれていないので、そのままで大丈夫です

---

## 4. Vercelでデプロイする

1. https://vercel.com にアクセスし、「Continue with GitHub」でログイン(GitHubアカウントと連携)
2. 「Add New...」→「Project」
3. 先ほどのリポジトリ(production-tools)を選んで「Import」
4. 設定画面はほぼそのままでOK(Frameworkは自動でNext.jsと認識されます)
5. 「Environment Variables」の欄で、以下を追加：
   - Name: `NOTION_TOKEN`
   - Value: 手順1でコピーした `secret_...` の文字列
6. 「Deploy」をクリックして数分待つ
7. 完了すると `https://production-tools-xxxx.vercel.app` のようなURLが発行されます

---

## 5. スマホで開く

1. 発行されたURLをiPhone/Androidのブラウザで開く
2. 共有ボタン(iPhone)またはメニュー(Android)から「ホーム画面に追加」を選ぶと、アプリのアイコンのように使えます
3. 奥さまにも同じURLを共有すれば、同じデータを見たり入力したりできます(Notion側の権限があれば誰でもアクセスできるURLなので、URLの共有先には注意してください)

---

## 6. 更新のしかた

コードを直したい場合(色を変える、項目を増やすなど)は、GitHub上のファイルを編集して保存するだけで、Vercelが自動的に再デプロイしてくれます。

---

## トラブルシューティング

- **「Notionへの接続に失敗しました」と出る**
  → NOTION_TOKENが正しく設定されているか、Vercelの Settings → Environment Variables を確認してください。設定を変えた後は「Redeploy」が必要です。

- **「データベースが見つかりません」と出る**
  → 対象のデータベースが、手順2のインテグレーションと共有(Connections)されているか確認してください。

- **車両予約の登録がNotionに反映されない**
  → Notion側で「予約名」「予約日時」「利用者」「行き先」「用途」のプロパティ名が変更されていないか確認してください(名前を変えると紐付けが外れます)。

---

## データベースの差し替えについて

別のデータベースに変更したい場合は、Vercelの環境変数に以下を追加すると、コードを直接編集しなくても切り替えられます(データソースIDはNotionの「fetch」で確認できます)。

- `NOTION_VEHICLE_DS_ID`
- `NOTION_EQUIPMENT_PERSONAL_DS_ID`
- `NOTION_EQUIPMENT_RENTAL_DS_ID`
